# 版本demo敏捷迭代需求提示词（第2次开发文档）

> 版本号：**1.1.0**（建议）
> 在《第1次开发文档》（v1.0.1）基础上迭代，遵循“小步交付、MVP优先、不过度设计、为未来预留扩展点”原则。
> 先输出任务拆分与实现计划，再按用户故事逐项编码；每完成一个用户故事，给出验收自测结果。

## 一、迭代目标

让工具从“固定居中的主窗口”升级为“**贴着光标的小浮窗 + 顺手即查**”：
1. 补上 v1.0.x 无法用拖动改变窗口大小的缺陷；
2. 选中文字后双击即可弹出迷你浮窗查拼音（不打开主窗口）；
3. 浮窗贴近光标/选区、可拖动、可固定、超时自动淡出；
4. 朗读更可控：语音可选、点单字朗读、抓取选区不破坏剪贴板；
5. 标调方式与多音字显示可切换。

## 二、本期范围

**本期实现：**
1. 无边框窗口支持从 8 个边缘/四角热区拖动改变大小；最大化状态下自动禁用（修复缺陷）。
2. 选中文字后**双击鼠标左键**弹出迷你浮窗显示选中字拼音；仅当检测到文本选区才触发，空白处双击不弹窗。
3. `auto_clipboard` 命中或 `Ctrl+Alt+P` 抓取选区时，浮窗贴近光标/选区（迷你模式）而非固定居中。
4. 迷你浮窗特性：可拖动、可固定(pin)、超时自动淡出；点喇叭朗读整段，点单字只读该字。
5. 朗读增强：可选 SAPI 嗓音（女/男/具体 VoiceId）、语速已有；抓取选区前备份并还原剪贴板。
6. 标调方式切换（符号调 hàn / 数字调 han4 / 无声调），对应 pypinyin `style`；多音字点击在多个读音间切换主显示。

**后续迭代（第3次及以后，本期仅预留）：**
生词本+历史记录、部首/笔画数/释义（CC-CEDICT）、批量整段转拼音、开机自启、多语言界面、内置手写板（Windows Ink）、OCR 识字、声调着色。

## 三、用户故事与验收标准

### US5：窗口拖动改变大小（缺陷修复）
**作为用户**，我希望无边框窗口能从边缘/四角拖动改变尺寸，而不只能靠设置宽度或最大化。

**验收标准：**
- 鼠标悬停窗口 N/S/E/W/四角时，光标变为对应双向箭头。
- 按住并拖动可改变窗口尺寸，最小 320×200，不出现内容溢出或崩溃。
- 标题栏拖动移动窗口保持不变，与边缘缩放互不冲突。
- 最大化状态下缩放自动禁用；缩放后关闭/隐藏时尺寸被记录，重启保留。

### US6：选中文字双击弹迷你浮窗
**作为用户**，我希望在任意程序选中文字后双击，立刻在光标旁弹出小窗看拼音，而不打开主窗口。

**验收标准：**
- 默认手势：选中文字后双击鼠标左键，在光标处弹出迷你浮窗显示选区拼音。
- 仅当存在文本选区时触发；空白处双击不弹窗，不干扰正常双击操作。
- 触发键/按钮可在设置修改（left/right/middle，修饰键 none/ctrl/alt/shift）。
- 也可配置为：双击 Ctrl 时若当前有选区则弹迷你窗而非首页（上下文分流）。

### US7：迷你浮窗交互与定位
**作为用户**，我希望浮窗贴近光标、能拖动/固定、不用时自动消失。

**验收标准：**
- `auto_clipboard` 或抓取选区触发时，迷你浮窗定位在光标/选区旁。
- 迷你浮窗可拖动、可固定(pin)；`popup_auto_hide_ms` 超时（0=不自动）后淡出。
- 点喇叭朗读整段，点拼音行单字只读该字；右键可复制拼音/加入生词本（生词本为后续）。

### US8：朗读增强
**作为用户**，我希望选择嗓音、逐字跟读，且抓取选区不会覆盖我已复制的内容。

**验收标准：**
- 设置可选 TTS 嗓音（female/male/具体 SAPI VoiceId），保存即时生效。
- 开启“点单字朗读”后，点击拼音行某字仅朗读该字。
- 开启“抓取选区不破坏剪贴板”后，`Ctrl+Alt+P` 前备份、读后还原剪贴板，用户原内容不丢。
- Windows 优先用 `uiautomation` 直接读选区；取不到再走剪贴板备份还原兜底。

### US9：标调方式与多音字切换
**作为用户**，我希望用习惯的标调方式看拼音，并能在多音字多个读音间切换。

**验收标准：**
- 设置项 `tone_style`：symbol / num / none，对应 pypinyin `style`，重启或即时生效。
- 多音字拼音行点击可在多个读音间切换主显示，其余读音仍列出。

## 五、技术实现约束

- 目标平台：跨平台（Windows / macOS / Linux），优先 Windows。
- **窗口缩放**：无边框窗口需手动实现 8 向缩放热区（边缘 `Frame`，`cursor` 设双向箭头，`<B1-Motion>` 改 `geometry`）；最大化时禁用；缩放后回写 `window_width/window_height`。
- **选中双击**：用 `pynput.mouse.Listener` 监听双击，经队列交主线程弹迷你 `Toplevel` 并定位到点击坐标；避免与双击 Ctrl 唤首页冲突。
- **选区读取**：Windows 用 `uiautomation` 直接取选区；兜底走“备份剪贴板→Ctrl+C→读→还原”。
- **拼音**：`pypinyin`，`style` 随 `tone_style` 切换，`heteronym=True` 支持多音字切换。
- **朗读**：Windows SAPI 多嗓音；抓取选区时备份/还原剪贴板。
- 配置持久化采用本地文件，「临时文件 + fsync + 原子替换」；缩放在隐藏/退出时记录尺寸。
- 全局监听跨平台权限失败需明确提示（沿用 v1.0.x 处理）。
