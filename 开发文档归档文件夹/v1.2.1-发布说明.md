# v1.2.1 发布说明

## 汉字拼音浮窗 v1.2.1（修复版）

这一版只解决一件事：**下载下来双击，窗口必须马上出现。**

### 修复

- **双击 exe 后屏幕上看不到程序**。两个原因叠加：
  1. 配置里 `start_hidden` 为 `true` 时，程序启动后直接驻留托盘，主窗口根本不弹。而 Windows 默认把新托盘图标收进任务栏「^」溢出区，用户双击 exe 后什么都看不到，只会认为"打不开 / 用不了"。
  2. 启动显示走的是裸 `deiconify()`，没带 `lift()` 和 topmost 重设。无边框窗口在部分 Windows + Tk 组合下会出现"窗口对象存在、但没被渲染"的状态。

  现在：**手动双击 exe 一律显示主窗口**，只有带 `--hidden` 参数（留给开机自启）才驻留托盘；启动显示改用完整的 `show()`（deiconify + topmost + lift + focus）；再加一条 0.9 秒兜底——若窗口仍未真正可见，自动再拉一次。

### 打包

- 新增**绿色版 zip**：解压即用，启动约 1 秒（单文件版首次启动要自解压 21 MB，约 2–5 秒，这期间屏幕上没有任何反应，很容易被误判成打不开）。
- 打包**关闭 UPX**：压缩拖慢启动，也更容易被杀软误报。
- 两个包都内置 Python 解释器与 VC++ 运行库，**不需要装 Python、不需要装任何运行库、不需要管理员权限**。

### 升级说明

- `schemaVersion` 仍为 4，无配置结构变化，旧配置直接可用。
- 之前勾选过「启动时直接驻留托盘」的用户，升级后手动双击会正常显示主窗口，设置项改为只对 `--hidden` 生效。

### 两个包怎么选

| 下载 | 大小 | 适用 |
| --- | --- | --- |
| `HanziPinyinPopup-portable.exe` | ~21 MB | 只要一个文件、随便放哪儿都能跑。首次启动慢 2–5 秒。 |
| `HanziPinyinPopup-v1.2.1-win64.zip` | ~21 MB | 解压即用、启动最快。注意 exe 要和同目录的 `_internal` 文件夹待在一起。 |

> 首次运行 Windows 可能弹 SmartScreen「Windows 已保护你的电脑」——点「更多信息 → 仍要运行」。
