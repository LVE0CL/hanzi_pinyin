# 版本demo敏捷迭代需求提示词（最终整合版）

请以敏捷开发方式实现本迭代，版本号：**1.0.0**。遵循“小步交付、MVP优先、不过度设计、为未来预留扩展点”的原则。先输出任务拆分和实现计划，再按用户故事逐项编码；每完成一个用户故事，给出验收自测结果。

## 一、迭代目标

应用启动后可常驻后台，并在系统托盘区显示图标；支持通过**双击指定按键（默认双击 Ctrl）启动/显示首页**；新增统一设置界面，入口包括**托盘右键菜单“设置”**和首页指定位置（圆圈1）的设置图标。**主窗口需实现无边框（或自定义标题栏）UI，右上角提供规范的窗口控制按钮（隐藏到托盘、全屏/最大化、退出），并支持鼠标拖动窗口。**

> **“首页”定义**：用户提供的主界面截图即为主界面（首页）。

## 二、本期范围

**本期实现：**

1. 启动后后台运行，托盘区显示图标。
2. 托盘右键菜单至少包含 **“首页”“设置”“退出”** 三项。
3. 支持双击触发键功能，默认双击 Ctrl，触发后**启动/唤起首页**；触发键可在设置中修改（现阶段仅支持单键双击）。
4. **主窗口自定义控制区与交互**：参考提供的截图，右上角从右至左依次为：退出（X）、全屏/最大化（□）、隐藏到托盘（-）。**必须支持通过按住顶部标题栏区域拖动窗口。**
5. 设置界面统一入口：托盘右键菜单“设置”进入；首页指定位置（圆圈1）新增设置图标，点击进入。
6. 设置项持久化保存，重启后保留。设置界面采用分组和配置模型设计，预留未来功能扩展点。

**本期不实现但需预留：**
开机自启、多语言、主题切换、云同步、复杂插件系统等。仅预留扩展结构，不实现具体功能。

## 三、用户故事与验收标准

### US1：后台托盘常驻与主窗口控制
**作为用户**，我希望应用能常驻托盘，并且能通过右上角的按钮明确控制窗口状态（隐藏、全屏、退出），同时能正常拖动窗口。

**验收标准：**
- 启动后托盘区出现应用图标。
- 托盘右键菜单包含“首页”“设置”“退出”，点击“退出”正常退出并清理托盘图标。
- 点击主窗口右上角的 `X` 按钮：**默认行为为直接退出应用**。
- 点击主窗口右上角的 `_` 按钮：**隐藏主窗口至后台托盘**，应用不退出。
- 点击主窗口右上角的 `□` 按钮：**主窗口放大至全屏/最大化**。
- **【新增】鼠标按住窗口顶部非按钮区域（标题栏），可以流畅拖动整个窗口。**
- 应用保持单实例运行，重复启动不产生多个托盘图标。

### US2：双击触发键可配置，双击启动首页
**作为用户**，我希望通过双击指定按键启动首页，并能修改触发键。

**验收标准：**
- 默认触发方式为“双击 Ctrl”，触发后**启动/显示首页**（若已打开则前置/唤起）。
- 设置界面可修改触发键，支持保存、取消、恢复默认，保存后即时生效或提示重启生效。
- 配置重启后仍保留。无效按键、冲突或监听失败有明确提示。
- 双击间隔默认建议 **400 ms**（跨平台折中值，GTK 默认），可在设置中调整。

### US3：设置入口统一
**作为用户**，我希望从托盘菜单或首页设置图标进入设置界面。

**验收标准：**
- 托盘右键菜单点击“设置”打开设置窗口。
- 首页指定位置（圆圈1）新增设置图标，点击打开同一设置窗口。
- 设置窗口为单实例，两个入口打开的是同一套设置界面和同一份配置。

### US4：设置界面可扩展
**作为开发者**，我希望设置界面按模块和配置模型组织，以便后续低成本扩展。

**验收标准：**
- 设置界面按“通用、快捷键、功能模块、关于”等分组组织。
- 配置使用统一模型持久化，包含 `schemaVersion`，预留版本迁移函数。
- 新增设置项只需增加配置定义和UI组件，不修改主流程。

## 四、设置界面信息架构建议
1. **通用**：启动行为、界面语言（预留）等。
2. **快捷键**：双击触发键配置、双击间隔阈值配置、恢复默认、冲突检测。
3. **功能模块**：本期可放已实现功能配置，未来新功能按模块注册。
4. **关于**：版本号 1.0.1、配置版本、帮助入口。
5. **扩展预留**：配置项与分组注册机制、`schemaVersion` 与迁移机制。

## 五、技术实现约束
- **目标平台**：跨平台（Windows / macOS / Linux）。
- **自定义窗口控制栏**：需跨平台支持无边框窗口。**【重点解决】必须实现窗口拖动功能**（如 Electron 中的 `-webkit-app-region: drag`，或系统级 API 的拖拽区域监听），确保顶部拖动区域与右上角按钮的点击事件（`no-drag`）不冲突。
- 托盘生命周期、窗口显示/隐藏、退出清理需统一管理。
- 全局按键监听需处理平台权限和限制（macOS主线程、Linux X11/Wayland差异），失败时明确提示。
- 配置持久化采用本地文件，建议原子写入防损坏。
- 设置窗口单例。首页圆圈1设置图标位置以最终提供的截图为准。
- 代码按用户故事小步提交，避免过度设计。
