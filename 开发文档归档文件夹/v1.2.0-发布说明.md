## 汉字拼音浮窗 v1.2.0

这一版把「好看、好控、好定制」补齐了：5 套 VS Code 风配色、可切换的置顶图钉、
重构过的快捷键，以及首次启动引导 + 15 个可选模块的开关框架。

### 新增

- **5 套主题 + 自定义背景**（US13）：`Dark+`（默认）/ `Light+` / `Dark Blue` / `Light Blue` / `Monokai`，
  颜色集中在单一 `THEMES` 表；可单独覆盖主背景色，其余颜色按明暗自适应，保存即重绘、不用重启。
- **图钉置顶**（US14）：标题栏改为 `📌 | − | □ | ×`，点图钉切换「始终置顶」，钉住为实心高亮。
- **首次启动引导 + 模块开关框架**（US11）：首启弹一次，勾选想用的功能；之后在「设置 → 功能模块」
  随时增删，未启用的模块不加载依赖、不显示入口。本期注册了 15 个可选模块，
  **框架已就位，内部功能在后续迭代逐个交付**。
- **内置手写板**（US12）：米字格画布可试写、撤销、清空；识别接入 Windows 系统手写面板
  （微软同款识别器），出字直接落进输入框并自动注音。
- **点浮窗外自动关闭**（US17）：迷你浮窗在外部点击时收起，已固定的浮窗不受影响，可开关。

### 变更

- **快捷键重构**（US15）：
  - 任一快捷键设为空 = 禁用；
  - 移除「抓取选中文字」热键（能力已被选中双击覆盖），旧配置自动清理；
  - 「选中双击」新增**键盘模式**，连续按两下功能键（默认 `Shift`）即可弹窗；
  - 功能键与唤起键相同时弹「是否互换」确认框，确定交换、取消回退。
- **设置图标统一为齿轮**（US10）：首页入口改为自绘齿轮位图，托盘菜单用齿轮字符。

### 修复

- **FR1 非中文/非标点过滤**：之前把英文、数字、符号也送去注音，出现无意义读音和串行。
  现在只让中文与标点进入注音：`Hello 你好 123！` → 只标注「你好！」，标点原样保留不注音。
  开关 `filter_non_han` 默认开启。
- 迷你浮窗拼音与汉字在部分字号下重叠（CJK Label 高度 ≠ linespace）。

### 升级说明

- 配置 `schemaVersion` 由 3 升到 4，旧配置自动迁移：清掉 `hotkey`、`dark/light` 主题自动映射到
  `dark_plus/light_plus`、补齐 `modules` / `first_run` / `handwriting_engine` 等字段，无需手动改。
- 首次启动会出现一次引导页；直接点「开始使用」即可。

### 已知限制

- 只在 Windows 10/11 上做了完整验证（托盘、朗读、UI Automation、手写面板均为 Windows 路径）。
- 15 个可选模块目前**只有开关框架**，打开开关不会变出新界面。
- 手写识别由系统手写面板完成（Win11 已移除 Tablet PC COM 组件，WinRT 异步结果在
  PowerShell 5.1 下无法取回）；离线 ONNX 引擎接口已预留，本期未随包提供模型。
