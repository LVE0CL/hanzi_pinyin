## 三、用户故事与验收标准

### US10：设置图标统一为齿轮
- 托盘右键菜单「设置」项、首页右下角入口，图标均渲染为齿轮（⚙ 或自绘齿轮位图），与文档表述一致。
- 浅色/深色主题下均清晰可见。

### US11：首次启动引导 + 功能模块化开关
- 首次启动（`first_run=true`）弹出一次性引导页，列出第 2 批全部可选功能（见下表 15 项），用户勾选启用；确认后写入 `modules` 并 `first_run=false`。
- 之后在「设置 → 功能模块」可随时增删启用，保存即时生效；未启用模块不加载依赖、不显示入口。
- 与 US4「设置界面可扩展」的分组注册机制一致，新增模块只需加一条 `modules` 定义。

### US12：手写功能（内置手写板）
- 应用内提供手写画板；写完识别为汉字并自动进入拼音流程。
- 引擎：`handwriting_engine="system"` 调用系统手写识别（Windows Ink / Tablet PC，即微软同款；质量等同商业输入法）；
  其他平台/离线可切换 `onnx` 离线模型（基于 CASIA-HWDB 等公开数据集训练）。
- 目标体验对齐微软手写 / 搜狗输入法：写歪、连笔也能较好识别（质量取决于所选引擎）。

### US13：主题与配色
- 设置「通用 → 主题」提供 5 套 VS Code 风配色：
  `Dark+`（默认深色）/ `Light+` / `Dark Blue` / `Light Blue` / `Monokai`。
- 默认选中 `Dark+`（深色）；新增「背景色」可选覆盖（null=跟随配色）。
- 切换即时生效；颜色映射集中在单一主题模块，便于扩展。

### US14：置顶改为可选项 + 图钉按钮
- 窗口右上角控制区顺序改为：**图钉 📌（最左）| − 最小化 | □ 最大化 | × 关闭**。
- 点击图钉切换「始终置顶」（`always_on_top`）；钉住为实心/高亮，松开为描边。
- 原 `always_on_top` 默认保持 `true`（维持现有行为），可由图钉切换。

### US15：快捷键重构
- **允许为空**：任一快捷键设为空字符串表示「禁用」，监听线程跳过该热键。
- **移除「抓取选中文字」热键**：其能力已被「选中双击弹浮窗」覆盖，设置项删除；旧配置 `hotkey` 字段在 `migrate()` 中清除。
- **选中双击支持键盘功能键**：新增「选中双击模式」= 鼠标 / 键盘；
  键盘模式下监听「选中双击的键盘功能键」，**默认为 `Shift`**，且**必须 ≠ 双击唤起键**（默认双击 Ctrl）。
- **冲突互换提示**：在设置中修改任一热键/功能键，若与「双击唤起键」重复，弹窗提示
  “该键与唤起快捷键冲突，是否互换唤起与选中的快捷键？”，需用户点击「确定」才执行互换，点「取消」则不改并回退输入。

  ### 缺陷修复 FR1：过滤非中文/非标点的字符
**现象**：输入框/浮窗会把中文、标点之外的字符（英文字母、数字、其它符号、emoji 等）
也送入拼音查询，产生无意义读音或显示异常。

**验收标准：**
- 对送入的内容做归一化：仅**中文（CJK）与标点**进入展示与拼音转换；其它字符默认过滤。
- pypinyin 仅对中文部分生效，标点原样保留、不参与注音。
- 设置提供开关 `filter_non_han`（默认开启）；关闭时保留原文（含英文/数字）仅作展示不注音。
- 回归：输入「Hello 你好 123！」→ 仅「你好！」被注音，英文数字不报错、不串行。

**实现提示**：新增 `filter_text()`，正则保留 `[\u4e00-\u9fff]` 及标点白名单，
主流程在取词后立即过滤再送拼音。

### US17：浮窗点击外部自动消失（可配置）
**作为用户**，我希望迷你浮窗在点击其外部区域时自动关闭，且该功能可在设置开关。

**验收标准：**
- 设置项 `popup_dismiss_on_outside_click`（默认开启）。
- 开启后，鼠标在浮窗矩形范围外点击 → 浮窗关闭（跨其它应用窗口的点击也能捕获）。
- 关闭该选项则浮窗常留，需手动关闭或快捷键收起。
- 与「超时自动淡出」「固定(pin)」互不冲突：已 pin 的浮窗不受此外部点击影响。

**实现提示**：用 pynput 鼠标监听 `on_click`，判定点击坐标是否落在浮窗 `winfo_x/y/width/height`
范围内，范围外则入队关闭；或 Toplevel `<FocusOut>` 隐藏（仅本应用失焦时）。
推荐 pynput 方式，因可捕获跨应用点击。

## 五、技术实现约束

- **目标平台**：跨平台，优先 Windows（图钉、手写引擎均以 Windows 为先）。
- **主题**：集中式配色表（5 预设 + 可选背景覆盖），切换即重绘；不硬编码颜色。
- **图钉**：在 − 左侧新增按钮，点击切换 `always_on_top`；图标用 📌 或自绘，置顶态高亮。
- **快捷键空值**：配置为空字符串时该热键禁用；pynput 注册前校验跳过。
- **移除抓取热键**：删除设置项与 `DEFAULT_CONFIG` 中 `hotkey`；`migrate()` 兼容旧配置清除该键。
- **选中双击键盘模式**：`select_double_mode="key"` 时监听 `select_double_key`（默认 `shift`），须 ≠ `trigger_key`；UI 保存时做冲突检测，弹确认框（确定=互换两值，取消=回退）。
- **手写**：Windows 调系统识别引擎；其他/离线用 ONNX 模型（推理用 onnxruntime）。
- **打包**：PyInstaller `--noconfirm --windowed` 生成 exe；资源（图标、模型、词典）随包；GitHub Release 上传 exe 作为资产。
- **配置持久化**：本地文件 + 原子写入；`schemaVersion` 本期 +1 并补 `migrate()`（清 `hotkey`、加 `modules/first_run/handwriting*`、主题字段扩展）。
