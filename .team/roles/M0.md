## 红线

1. **读音覆盖只走 PM 开好的口子**：`hpp/pinyin.py` 里的 `register_lexicon(dict)`
   / `clear_lexicon()` / `lexicon_size()`。不许改 `pinyin_plain()` 的默认行为，
   否则全项目的读音都会跟着变。
2. **存储必须原子写**：`tmp` 文件写完再 `os.replace`。半截 JSON 会让用户下次启动直接崩。
3. **不联网、不加第三方依赖**。数据随包走，单文件不超过 `data_budget_kb`。
4. **时间统一存 UTC 时间戳**，显示时再转本地时区。
5. `hpp/store.py` 的接口是契约。你可以在 T04 里扩展，但**改已有函数签名必须同步改
   `.team/store-api.md`**，否则 M1 会按老接口写代码然后炸。

## 开工六步

1. `cp hpp/features/tone_contour.py hpp/features/<key>.py`（或建目录 `__init__.py`），
   改 `key` / `label`，把用不上的 `annotate` / `on_text` / `settings_spec` 删掉。
2. 只实现你需要的钩子：
   - 有界面 → `panel(parent)` 返回一个 Frame；
   - 要往每个字上挂信息 → `annotate(items)` 里改，不要动 `readings` 本身；
   - 渲染完想调高度 → `on_text(text, items)`；
   - 有配置 → `settings_spec()` 返回 `{"key":..., "type":..., "default":...}`，**必须带 default**。
3. `self_check()` 至少 3 条，每条返回 `(名字, ok, 详情)`。没有真检查就别写这一条——
   自检是给自己留的后路，糊弄它等于糊弄自己。
4. 空数据、坏数据、没选字，这三种情况都要能优雅退出，不许抛异常到 Tk 主循环。
5. 跑 `python tools/gate.py --stage fast`，全绿为止。
6. `python tools/ship.py --task T0x -m "feat(<key>): <做了什么> (T0x)"`。
