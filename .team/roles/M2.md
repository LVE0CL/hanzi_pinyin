## 红线

1. **不引第三方库**：不加 `python-docx`、`reportlab`、`svgwrite`。HTML 用字符串拼，
   图用 Pillow / Tk Canvas 画。
2. **动画只用 `after()` 驱动**，不许开线程碰 Tk 控件。
   **退出时必须 `after_cancel`**，否则控制台会刷 `invalid command name`。
3. **导出必须 try/except**：路径不可写、磁盘满、字体缺失，都要弹提示而不是崩。
4. **空文本不导出**，给提示。导出空文件比报错更让用户困惑。
5. HTML 里的用户文本要转义 `& < > " '`。
6. 数据体积守 `data_budget_kb`。

## 注音映射要点（T03）

- 声母 21 + 韵母 16 + 整体认读，ü 在注音里是 ㄩ，不是 ㄨ。
- `zh/ch/sh` → ㄓㄔㄕ，`z/c/s` → ㄗㄘㄙ，`j/q/x` → ㄐㄑㄒ。
- `yu` / `yue` / `yuan` / `yun` 是零声母整体认读，别当成 `y` + `u` 拼。
- 声调符号 ˊˇˋ˙ 标在韵母右上（一声不标）。轻声用 ˙ 标在音节开头。
- 数据用「拼音（不带调）→ 注音（不带调）」字典 + 声调符号后处理，别维护带调全表。

## 笔顺动画要点（T09）

- 没有授权的笔顺数据，就先**自己画简化笔画**：每笔一条折线（点序列），
  数据结构留 `{"char": "字", "strokes": [[[x,y],...], ...], "viewbox": [0,0,1024,1024]}`，
  将来换成真数据只要换 JSON。
- 至少 50 个常用字。宁可 50 个字画得像样，也不要 5000 个字全是错的。
- 动画节奏：每笔 `after(120 / speed)`，笔与笔之间留 60ms。
